# newellize

obamify but Gabe Newell. Rearranges the pixels of a sample image until it looks
like him, then plays the transformation.

<https://mithrilbytes.github.io/newellize/>

Static site, no build. Double-click index.html or serve the folder.

Different target image:

    ./tools/embed.sh portrait.jpg

Idea from [obamify](https://github.com/Spu7Nix/obamify) by Spu7Nix. Fan parody,
not affiliated with Valve. MIT.
